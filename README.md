# Alekz — Personal Portfolio

A responsive, single-page portfolio for web development, digital communications and project delivery.

## Run locally

Open `index.html` in a browser. The site is static HTML, CSS and JavaScript; no build step is required.

## Deploy

This repository can be imported into Vercel as a static site. Use the repository root as the project root and leave the framework preset as **Other**. No build command or output directory is required.

## Notes

- Mobile-first responsive layout.
- Reduced-motion accessibility support.
- Project descriptions reflect contribution scope; add verified screenshots and personal contact details before wider promotion.
